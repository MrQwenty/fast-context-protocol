# CGP documentation site

Framework-style documentation for Context Governance Protocol, built with Astro Starlight.

## Local development

```bash
cd website
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The static output is written to `website/dist`.

## GitHub Pages

The repository includes a Pages workflow. Configure **Settings → Pages → Source → GitHub Actions**, then run the `Documentation` workflow or push a change under `website/`.
