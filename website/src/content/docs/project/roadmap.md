---
title: Roadmap
description: Delivery sequence for the protocol, gateway, ecosystem and governance layers.
---

## 0.1 — Core protocol

- discovery, request and Context Plan;
- token and byte budgets;
- content-addressed nodes;
- inline, reference and fetch delivery;
- Go provider, client and conformance baseline.

## Privacy extension

- local-only privacy contract;
- redaction, scoped pseudonymization and per-document anonymization;
- encrypted reversible vault;
- residual leak scan and fail-closed gate;
- local text, OpenXML, PDF and OCR extraction.

## 0.2 — Synchronization and integrity

- context patches and invalidation;
- resumable priority streams;
- tokenizer profiles;
- signed manifests and receipts;
- cross-provider composition;
- dependency-aware deletion.

## 0.3 — Simple integration

- MCP resource adapter;
- OpenAI-compatible local proxy;
- Anthropic, Gemini, Azure OpenAI and Ollama adapters;
- `cgp init --profile eu-safe`;
- `cgp run -- <application>`;
- `cgp doctor`, `cgp explain` and `cgp audit`;
- TypeScript, Python and public Go SDKs;
- TTFC, TTUC, token-efficiency and privacy benchmarks.

## 0.4 — Trust and governance

- EU Compliance Envelope;
- Context Trust Firewall;
- purpose, retention and data-rights propagation;
- AI Bill of Materials and evidence export;
- signed regulatory policy packs;
- transparency and human oversight;
- compliance simulator;
- EU-only provider routing;
- explainable policy decisions.
