CGP is maintained as an open-source pre-alpha project. Community support is best effort and does not include legal advice, compliance certification or a production service-level agreement.

## Ask for help

Use the repository's structured issue forms:

- Bug Report;
- Feature Request;
- Protocol Proposal;
- Documentation;
- Question or Support.

Before opening an issue:

1. search existing issues;
2. read the relevant documentation;
3. remove all secrets and personal or customer data;
4. provide a minimal synthetic reproduction.

Read the full [Support Policy](https://github.com/MrQwenty/fast-context-protocol/blob/master/SUPPORT.md).

## Sponsor development

You can fund continued maintenance through [GitHub Sponsors](https://github.com/sponsors/MrQwenty).

Sponsorship supports work such as:

- protocol and schema design;
- privacy and security hardening;
- interoperability fixtures;
- conformance testing;
- documentation;
- SDK and adapter development;
- regulatory-source maintenance.

Sponsorship does not create a private support contract, guarantee a feature, or influence protocol conformance decisions.
