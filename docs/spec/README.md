# FCP specifications

| Document | Status | Purpose |
|---|---|---|
| [FCP-0001](FCP-0001.md) | Draft | Core protocol model and HTTP/JSON wire contract |
| [FCP-0005](FCP-0005.md) | Draft | Local document privacy gateway, anonymization, pseudonymization, and privacy receipts |

Protocol proposals use sequential `FCP-NNNN` identifiers. A proposal must document compatibility, security implications, privacy implications, and conformance requirements before acceptance.
