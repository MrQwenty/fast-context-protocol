# Security Policy

FCP is pre-alpha and must not yet be used as a security boundary in production.

Please report vulnerabilities privately through GitHub's security advisory feature once enabled for the repository. Do not include secrets, customer data, or exploit details in public issues.

The highest-priority areas are authorization bypass, cross-tenant context leakage, cache poisoning, digest confusion, provenance forgery, replay, prompt injection propagation, and denial of service through oversized or adversarial context.
